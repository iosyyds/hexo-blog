欢迎来到我的博客！这里将记录我的生活、学习与思考。

这个博客使用 [Hexo](https://hexo.io/) 驱动，搭配 [AnZhiYu](https://github.com/anzhiyu-c/hexo-theme-anzhiyu) 主题搭建，完全免费、无需购买服务器。

## 你可以在这里看到

- 技术文章
- 学习笔记
- 生活随想

## 如何开始写文章

在博客根目录运行下面的命令即可创建新文章：

```bash
hexo new "我的第一篇文章"
```

然后用 Markdown 编辑 `source/_posts/` 下的文件即可。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `hexo new "标题"` | 新建文章 |
| `hexo g` | 生成静态文件 |
| `hexo s` | 本地预览 |
| `hexo d` | 部署上线 |
